# Canopy branding

**Canopy** is the chosen project/app name for the separate free, open-source
native game launcher described in issue #34.

`Canopy.png` is the user-approved provisional icon, selected on 2026-10-25:
three green, mint and teal leaves framing a play triangle on a charcoal tile.
The requested visual direction is simple Adwaita / GTK 4 styling, using the
user-supplied KNX Panel icon as a style reference. This is AI-generated artwork
created for Canopy, not a Nintendo game icon or extracted game content.

The source PNG is retained unchanged at 1254 × 1254 pixels with RGBA transparency.
It is concept/source artwork, not a compiled Apple asset catalog. Platform asset
sizes, full-bleed Apple treatment and small symbolic variants can be derived when
the separate Canopy app target is implemented. Do not substitute this artwork
into the working TOTK app or change its bundle identity.
